## 1. 引物设计与评估（Primer Premier 5 工作流）

### 1.1 设计流程

1. **模板准备**：从 BioEdit 中拷贝目标序列（注意：不要把载体序列一起带入）；
2. **设定搜索区间**：勾选 Search 的 `PCR Primers`（如需 5' 端加接头则勾选相关选项），
   按目的选 `Pairs` / `Sense` / `Antisense`；
3. **搜索**：`Primer → Search`，在候选列表中挑选；
   - 常规 PCR：产物长度设 300–1000 bp；
   - qPCR：产物 80–250 bp、跨内含子（可用本包 `02_primer_design.py --mode qpcr` 自动完成）；
4. **看评分与敏感位点**：检查候选的 Tm、GC%、发夹（Hairpin）、二聚体（Dimer）、错配（False Priming）；
5. **导出与复核**：选定引物后用 BLAST 核对特异性；qPCR 引物再核对溶解曲线与扩增效率。

### 1.2 评估与修改原则（要点）

| # | 原则 | 参考阈值 |
|---|---|---|
| 1 | 长度 | 18–24 nt（qPCR 18–22 nt） |
| 2 | GC 含量 | 40–60%（避免 <35% 或 >65%） |
| 3 | Tm | 55–65 ℃，**上下游 Tm 差 ≤2 ℃**（理想 ≤1 ℃） |
| 4 | 3' 端碱基 | 避免 3' 端连续 ≥3 个 G/C 或 3' 端为 T（T 易错配滑移） |
| 5 | 连续单碱基 | 避免 ≥4 个连续相同碱基（尤其 G） |
| 6 | 二级结构 | 发夹 Tm 低于退火温度；**避免引物内部/之间二聚体** |
| 7 | 3' 端互补 | 上下游引物 3' 端不得互补（防止引物二聚体优先扩增） |
| 8 | 错配 | 3' 端最后 5 nt 避免错配位点（False Priming 检查） |
| 9 | 特异性 | BLAST 全基因组核对；多拷贝基因选特异区或保守区（视目的） |

> 以上"评估—修改"循环即引物设计的核心：任何一项不达标就回到第 4–8 条修改候选，
> 本包 `02_primer_design.py` 已将上述指标全部量化输出（含发夹/二聚体 Tm 数值），可直接判读。

### 1.3 加接头引物（克隆用）

- 同源重组/酶切连接所需接头**加在 5' 端**；接头不与模板配对，Tm 分开计算（以模板配对区为准）；
- 模板配对区长度 ≥18 nt，接头区 GC 尽量 40–60%（同源臂要求见 §2）；
- 有方向要求的引物（CRISPR 构建 gRT/U6T 等）注意互补链方向——本包 `01_sgrna_design.py` 输出的
  构建引物已自动处理方向。

## 2. 同源重组载体构建

### 2.1 通用流程（In-Fusion / Gibson / ClonExpress 类）

```
线性化载体（酶切或反向 PCR） → 插入片段 PCR（两端带 15–20 bp 同源臂）
→ 重组反应（37 ℃ 或 50 ℃，按试剂盒） → 转化 DH5α → 菌液 PCR 初筛
→ 测序验证（覆盖全部插入片段 + 连接点两端载体各 ≥100 bp）
```

### 2.2 同源臂设计要点

| 项目 | 要求 |
|---|---|
| 长度 | 15–20 bp（片段短/GC 低时取 20 bp 以上） |
| GC | 40–60%，避免连续单碱基和发夹 |
| 位置 | **载体端同源臂**取自线性化位点两侧（必须与载体序列完全一致）；**片段端**取自插入片段两端 |
| 移码 | 表达构建注意读码框；融合标签在 N/C 端分别核准 |
| 酶切方案 | 双酶切时两酶位点距离 ≥5 bp、缓冲液兼容；反向 PCR 线性化注意 5' 磷酸化 |

### 2.3 常见问题排查

| 现象 | 排查方向 |
|---|---|
| 平板上全是空载背景 | 线性化载体未切完全 / 未去磷酸化；重组酶失活；同源臂错配 |
| 克隆数极少 | 同源臂太短或含二级结构；插入片段浓度不足；反应温度/时间不足 |
| 测序发现片段内部突变 | PCR 酶保真度（用高保真酶）；模板质量 |
| 菌落 PCR 阳性但测序不对 | 引物非特异；多个片段混入；挑斑不纯 |

## 3. RNAi 载体构建（pYLRNAi.5 类）

### 3.1 靶片段选择

1. 从目标基因 **cDNA** 选 **300–500 bp** 片段；
2. 避开与其他同源基因高度保守的区域（防止误伤旁系同源基因）；
3. 避免与基因组其他基因存在连续 ≥21 nt 的相同序列（RNAi 脱靶风险）；
4. 避开靶基因 5' UTR/起始密码子附近——选 CDS 中段更稳。

### 3.2 构建流程（发夹结构）

```
靶片段正向片段 PCR（引物 A+B） ──┐
靶片段反向片段 PCR（引物 C+D） ──┴→ 通过中间接头/intron 连接
→ 双元载体（pYLRNAi.5 类，含 intron 分隔的反向重复位点）
→ 酶切-连接（或重组）→ 转化 → 测序确认正向+反向两拷贝均正确
→ 转化农杆菌 → 遗传转化 → T0/T1 鉴定 → qRT-PCR 确认敲低效率
```

### 3.3 要点

- **必须同时测序正、反两个方向拷贝**：反向片段方向错误是构建失败主要原因；
- 敲低效率验证：取 T1 单株抽穗前叶片 RNA，qRT-PCR（`02_primer_design.py --mode qpcr` 设计引物，
  引物置于靶片段**之外**的 3' 端区域更严格）；
- RNAi 表型常为部分敲低（不是零余），需多株系 + 多代表型统计支撑结论。

## 4. 蛋白表达纯化与 SDS-PAGE

### 4.1 标签载体选择

| 标签 | 载体示例 | 优势 | 注意 |
|---|---|---|---|
| **His**（6×His） | pET 系列 | 分子量小、镍柱一步纯化 | 真核蛋白易包涵体；低表达时收率低 |
| **GST** | pGEX 系列 | 促溶、谷胱甘肽亲和 | 26 kDa 标签大，融合蛋白活性可能受影响；洗脱需还原型谷胱甘肽 |
| **MBP** | pMAL 系列 | 强促溶（对难溶蛋白首选） | 标签更大，需考虑切割后残留 |

- N 端/C 端放置依蛋白性质与后续实验（如需要保留活性位点）决定；
- 切割标签（PreScission/TEV/凝血酶）位点设计在标签与目的蛋白之间，注意读码框。

### 4.2 同源臂引物与克隆

- 按 §2 同源重组流程将目的蛋白 CDS 克隆进表达载体；
- 引物设计时**删除信号肽/跨膜区**（若做大肠杆菌表达）；
- 载体线性化常用 NdeI/BamHI/EcoRI 等，注意与目的片段内部位点不冲突（先做虚拟酶切）。

### 4.3 表达与菌体破碎（流程要点）

```
转化 BL21(DE3) → 小试（16–37 ℃ 诱导，IPTG 0.1–1 mM，梯度试验）
→ SDS-PAGE 检查可溶/沉淀 → 放大培养 → 收菌 → 破碎
```

**菌体破碎**：
1. 菌体用裂解缓冲液（含 PMSF/DTT 或蛋白酶抑制剂）重悬；
2. **冰浴超声破碎**：功率 30–40%，工作 3 s / 间歇 5 s，循环至菌液清亮（全程冰浴，避免过热）；
3. 4 ℃ 12000–15000 rpm 离心 20–30 min，上清 = 可溶蛋白，沉淀 = 包涵体（可尿素溶解复性）；
4. 上清过 0.22/0.45 μm 滤膜后上亲和柱纯化。

### 4.4 SDS-PAGE 标准配方

| 组分 | 12% 分离胶（10 mL） | 5% 浓缩胶（5 mL） |
|---|---|---|
| H₂O | 3.3 mL | 3.4 mL |
| 30% Acr-Bis (29:1) | 4.0 mL | 0.83 mL |
| 1.5 M Tris-HCl (pH 8.8) | 2.5 mL | — |
| 1.0 M Tris-HCl (pH 6.8) | — | 0.63 mL |
| 10% SDS | 0.1 mL | 50 μL |
| 10% APS（过硫酸铵，现配） | 0.1 mL | 50 μL |
| TEMED | 4 μL | 5 μL |

**缓冲液**：
- 5× 电泳缓冲液（1 L）：Tris 15.1 g + 甘氨酸 94 g + SDS 5 g，稀释后使用；
- 5× 上样缓冲液：含 250 mM Tris-HCl (pH 6.8)、10% SDS、50% 甘油、0.5% 溴酚蓝、5% β-巯基乙醇（或 DTT）。

**操作要点**：上样前 95 ℃ 变性 5–10 min；浓缩胶 80 V、分离胶 120 V；考马斯亮蓝染色 ≥1 h，脱色液脱色至背景干净。

**结果判读**：
- 目标带小于预期 → 降解/截短（加蛋白酶抑制剂、低温操作）；
- 上清无带、沉淀有带 → 包涵体（降诱导温度至 16 ℃、降 IPTG、换 MBP 标签、加分子伴侣）；
- 条带弥散 → 超声过度或样品盐浓度高。

## 5. 烟草亚细胞定位

### 5.1 载体与菌株

- 融合表达载体：35S::Gene-GFP（或 Gene-mCherry）；对照：空 GFP；
- 菌株：农杆菌 **GV3101**（或 EHA105）；辅助质粒 p19（沉默抑制子，提高表达）。

### 5.2 注射流程

1. 载体转农杆菌 → 28 ℃ 培养至 OD₆₀₀ ≈ 0.8–1.0；
2. 离心收集菌体，用悬浮液（10 mM MES pH 5.6 + 10 mM MgCl₂ + 100–200 μM 乙酰丁香酮）洗一次并重悬；
3. 稀释至 OD₆₀₀ ≈ 0.5–0.8，**室温静置 1–3 h**；
4. 用无针注射器从烟草叶片**背面**压渗注射（避开主叶脉），标记注射区；
5. 正常培养 2–3 天后观察（共表达 p19 时表达量更高）。

### 5.3 共聚焦观察

- 激发：GFP 488 nm / mCherry 561 nm；先看空 GFP 对照确定细胞质/核定位背景；
- **必须做共定位**：与已知标记（核：NLS-mCherry；膜：mCherry 膜标记；叶绿体自发荧光避开）共注射；
- 拍照记录：全细胞视野 + 局部放大；每个构建至少 3 片叶、≥10 个细胞重复。

### 5.4 要点

- 叶绿体自发荧光在 500–550 nm 会干扰 GFP 信号 → 选下表皮细胞或采用光谱拆分；
- 注射后叶片若黄化坏死，降低菌液浓度或换更幼嫩叶片；
- 亚细胞定位结论表述为"在烟草细胞中主要定位于…"，水稻内验证建议原生质体瞬时转化复核。

## 6. LUC 互补实验

### 6.1 Split-LUC 互补成像（检测蛋白-蛋白互作）

```
GeneA-nLUC + GeneB-cLUC（GV3101）共注射烟草 → 2–3 天
→ 涂抹荧光素底物（1 mM luciferin，含 0.01% Triton X-100）
→ 暗适应 5–10 min → CCD 成像（曝光 1–10 min）
```

- 对照：nLUC/cLUC 空载体组合（阴性）、已知互作对（阳性）；
- 判断：**且仅当**两融合蛋白共表达出现明显荧光信号 → 互作阳性；单一融合 + 空载不得发光；
- 也可用原生质体体系（PEG 转化后测酶活）定量复核。

### 6.2 LUC/Ren 双报告转录活性（判断转录激活/抑制）

- 体系：效应子（35S::TF）+ 报告子（靶基因启动子::LUC）+ 内参（35S::Ren）；
- 共注射烟草叶片，2–3 天后 Dual-Luciferase 检测 LUC/Ren 比值；
- TF 使比值显著升高 → 转录**激活**；显著降低 → 转录**抑制**；
- 对照：空效应子（35S::空）为基线；启动子截短/突变版本用于定位响应元件。

## 7. mhiTAIL-PCR（T-DNA 侧翼序列扩增）

改良高热不对称交错 PCR（hiTAIL-PCR 变体），用于**定位 T-DNA 插入位点、扩增侧翼序列**。

### 7.1 引物体系

| 引物 | 方向 | 说明 |
|---|---|---|
| SP1 / SP2 / SP3 | 由 T-DNA 边界向基因组外 | **嵌套**特异引物：SP1 最近边界，SP2、SP3 依次向内（各相距约 100–150 bp） |
| LAD1–LAD4 | 随机简并短引物 | 低 Tm（约 30–45 ℃），与 SP 配对做不对称扩增 |

- 左右边界各设计一套（LB 与 RB 方向）；引物 Tm：SP ≈ 60–65 ℃（长 22–26 nt，GC 45–60%）。

### 7.2 流程

```
预扩增（SP1 + LAD 简并引物池，低严紧度） 
→ 第 1 轮嵌套（SP2 + LAD，产物 1:50 稀释做模板） 
→ 第 2 轮嵌套（SP3 + LAD） 
→ 电泳：挑第 2/3 轮特异条带（逐轮变短）→ 直接 Sanger 测序
→ 序列 BLAST 定位插入位点（水稻参考基因组）
```

### 7.3 要点

- 第 2 轮产物为多条带正常；**特异带特征 = 相对第 1 轮条带变短约 100–150 bp**（对应 SP2/SP3 间距）；
- 若条带弥散，升高退火温度或减少循环数；若无产物，检查模板质量、核对边界序列方向；
- 与全基因组测序（WGS）方案互补：WGS 更适合批量样品，mhiTAIL-PCR 成本低、单样品即可做。

## 8. GUS 组织化学染色

### 8.1 载体与材料

- 启动子::GUS 载体（pCAMBIA1301/pBI101 类），或基因融合 GUS；
- 转基因阳性株（T1/T2 单拷贝株系优先）。

### 8.2 染色液与流程

**染色液配方**（现配，避光）：

| 组分 | 终浓度 |
|---|---|
| 磷酸钠缓冲液 pH 7.0 | 50 mM |
| X-Gluc（DMSO 预溶） | 1 mM |
| 铁氰化钾 K₃[Fe(CN)₆] | 0.5 mM |
| 亚铁氰化钾 K₄[Fe(CN)₆] | 0.5 mM |
| EDTA | 10 mM |
| Triton X-100 | 0.1% |

**流程**：取样 → 丙酮固定（可选，冰浴 15–20 min）→ 染色液浸润、**真空抽气 10–30 min**（组织下沉为准）→ 37 ℃ 避光 4 h 至过夜 → 70% 乙醇脱色（换液 2–3 次至背景干净）→ 体视镜/显微镜观察拍照。

### 8.3 要点

- 铁氰化钾/亚铁氰化钾为**氧化剂**，防止反应产物扩散（过量会抑制酶活，浓度可 0.5–2 mM 调整）；
- 染色时间需预实验摸梯度（过染导致全组织蓝染，失去时空信息）；
- 定量主张用 **MUG 荧光法**（4-MUG 底物，测 4-MU 荧光）替代目视比较；
- 阴性对照：野生型（非转基因）同部位必须无色；不同株系间比较需同期取样染色。

## 9. 序列分析（BioEdit）

| 功能 | 操作 | 用途 |
|---|---|---|
| 峰图查看 | File → Open（.abi/.scf） | 查看 Sanger 峰图，识别双峰（杂合/混合） |
| 序列编辑 | 双击序列区 | 校正错误碱基（在峰图上核对后再改） |
| 多重比对 | Accessory → ClustalW | 编辑体突变比对、多材料 SNP 核对 |
| 载体污染检查 | 与载体序列比对 | 剔除克隆时带入的载体序列 |
| 翻译/ORF | Sequence → Translate | 检查移码、提前终止（编辑体解码） |
| 酶切位点 | Restriction 工具 | 虚拟酶切核对克隆方案 |
| 引物设计辅助 | 选区域 → 设计 | 快速设计（精确设计走 §1 或本包工具） |

**典型工作流 · 编辑体测序比对**：
1. Sanger 峰图导入 BioEdit → 剔除低质量两端；
2. 与野生型靶点区序列 ClustalW 比对 → 确认 indel 位置与类型；
3. 有双峰 → 疑似杂合/双等位：用 **DSDecodeM**（http://skl.scau.edu.cn/dsdecode/）
   解码（粘贴测序文件 + 靶点序列）；
4. 翻译检查：非 3 倍数 indel → 移码突变（敲除目的达成）；3 倍数 → 小缺失（可能保留部分功能）。
