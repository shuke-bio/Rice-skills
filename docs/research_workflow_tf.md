# 转录因子功能研究全流程（研究路线图）

## 1. 基因背景调查（掌握目前对该基因的认识）

| 维度 | 内容与工具 |
|---|---|
| 基因注释 | ID、基因结构、GO/KEGG；**PlantTFDB**（转录因子家族与 DNA 结合结构域确认） |
| 家族与文献 | 直系/旁系同源基因 + 已发表文献梳理 |
| 序列分化 | **RFGB 单倍型分析**（3K 水稻）、实验室重测序数据；Sanger 验证建议覆盖野生稻/农家种/现代种/四倍体材料 |

## 2. 基因功能研究（该基因调控什么性状）

### 2.1 基因编辑突变体（CRISPR/Cas9）

- **目的**：改变蛋白序列 → 观察表型。**周期**：载体构建 1 个月 → 转化 3 个月 → T0-T2 1.5 年 → 杂交分离 1 年 ≈ **≥2.5 年**
- **转化期间备好**：① WT 基因分型引物；② 受体靶点区验证引物（靶点 ±100 bp）；③ 四倍体材料可开发 HiDecode 引物
- **T0**：T-DNA 检测（筛有 T）→ WT 特异引物筛选（无 WT 带 = 候选突变株）→ 靶点 Sanger（**重点关注**：纯合非三倍数突变；多碱基 indel 的杂合/双等位）→ 收种 + 性状调查（花粉育性/结实率/穗长/粒长粒宽/百粒重）→ 开发纯合突变基因型特异标记
- **T1**：筛选无 T 植株（≥3 个株系）→ 分型引物确认基因型 → 抽检测序 → 材料固定 + 细胞学 → 突变体×WT 杂交 → 拍照与性状调查
- **T2**：性状调查、细胞学、转录组取样；大量收集无 T 纯合种子用于**遗传互补**
- **F1/F2**：杂种鉴定（无 T + WT/mut 基因型）→ F2 基因型比例 + 表型连锁分析

### 2.2 遗传互补材料

- **目的**：突变体重转完整基因，看表型是否恢复。**周期** ≈ **≥1.5 年**（载体 1 月 + 转化 3 月 + T0-T1 1 年）
- **T0**：阳性苗鉴定（通用引物 PCR + 测序）→ 全部单株收种 + 性状调查 → 表型恢复株繁殖 T1
- **T1**：筛选单拷贝杂合分离株系（有:无 T ≈ 3:1）×3 → 比较有无 T-DNA 的表型差异

### 2.3 RNAi / 过表达材料

- **目的**：下调/上调表达 → 观察表型。**周期** ≈ **≥2 年**
- **T0**：阳性苗鉴定 → 全部单株收种 + 性状调查（花粉育性/结实率/穗长/粒长粒宽/百粒重）→ 表型显著变化株繁殖 T1
- **T1**：筛选 3:1 分离株系 ×3 → **TAIL-PCR / 酶切自连**定位 T-DNA 插入 → qRT-PCR 确认表达变化 → 锁定上下调极显著纯合株 → 细胞学 + 性状调查
- **T2**：性状、细胞学、qRT-PCR（检测下游基因）

## 3. 突变体细胞学研究（功能起始时期及表现）

> 配套：花粉育性、胚囊受精、减数分裂细胞学观察。

## 4. 基因表达模式研究（时空规律）

| 层次 | 方法 |
|---|---|
| 生信分析 | **RiceXPro**、**Rice eFP Browser**、GEO Profiles、**IC4R/RED**、Expression Atlas、实验室转录组数据 |
| 检测 mRNA | **qRT-PCR**（根/茎/叶/穗/各阶段花药与子房）、**GUS 转化与染色**、原位杂交（细胞级定位） |
| 检测蛋白 | mVenus 转化苗、**瞬时转化**（烟草叶片 / 水稻原生质体亚细胞定位）、Western blot、间接免疫荧光 |

## 5. 分子机理

### 5.1 转录活性测定
**LUC/Ren 双荧光素酶**体系：判定该转录因子为转录激活还是抑制型。

### 5.2 突变体下游基因表达谱
- **转录组取样**：细胞学异常**前/中/后**三个时期（额外固定样品用于 WE-CLSM 定时期）
- 常规分析：数据质量 → 重复相关性 → DEG → **GO/KEGG 富集**（定位表型相关通路）→ **qRT-PCR 验证 ≥10 个 DEG**
