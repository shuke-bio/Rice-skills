# Decision Layer — English Scenario Cards

Ten English scenario cards mirroring `docs/decision/scenario_*.md`.
Each card covers prerequisites, design checks, three tiers, whitelist-only sources,
failure modes and the script map.

| Card | Topic |
|---|---|
| `scenario_rnaseq.md` | Bulk RNA-seq |
| `scenario_gwas.md` | GWAS (natural population, families, multi-parent) |
| `scenario_multiomics.md` | Transcriptome x metabolome integration |
| `scenario_singlecell.md` | Single-cell and spatial omics |
| `scenario_metabolome.md` | Metabolomics (stand-alone) |
| `scenario_qtl.md` | QTL and BSA |
| `scenario_gs.md` | Phenomics and genomic selection |
| `scenario_pangenome.md` | Pangenome and structural variation |
| `scenario_epigenome.md` | WGBS / ATAC / ChIP |
| `scenario_proteome.md` | Proteomics |

Citation policy: A1-A3 journal whitelist only; non-whitelisted method papers are
named as tools without being used as design sources. See `../README.md`.
