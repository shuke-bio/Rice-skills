# 场景卡：单细胞与空间组学

## 1. 适用与前提

- 单细胞：scRNA-seq / snRNA-seq，目标是细胞类型、组成差异、轨迹、调控；
- 空间：Stereo-seq / Visium 等，目标是空间域、区域特异表达、邻域互作；
- 前提：**以生物学样本为重复**；样本级 QC 必须在合并之前完成；切片/批次需记录。

## 2. 先判断"能不能做组间比较"

| 检查 | 不通过时的替代 |
|---|---|
| 每组 ≥2 个生物学样本 | 只有 1 个样本/组 → 只做描述性图谱，不做组间统计 |
| 样本级 QC 指标可解释（线粒体%、基因数） | 阈值异常 → 按组织重设并报告 |
| 批次信息完整 | 批次缺失 → 只能做保守整合，结论标注探索性 |
| 空间坐标与图像配准 | 错位 → 先修正，否则空间结论无效 |

## 3. 三档方案

### 最小可行
1. `single_cell/01_scanpy_pipeline.py`：QC、归一化、HVG、PCA；
2. 按样本报告细胞数与中位基因数；
3. 整合（Harmony/scVI，由脚本参数控制）。

### 标准
1. 聚类 + marker 注释（可用参考图谱做标签迁移）；
2. **细胞类型比例差异**（以样本为单位，不是以细胞为单位）；
3. 伪 bulk 差异表达，避免单细胞检验的伪重复。

### 进阶
1. 轨迹推断（需明确起点与方向）；
2. SCENIC 类调控网络（资源消耗大）；
3. 空间映射或多切片联合。

## 5. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| 组间差异只出现在比例 | 消化/捕获偏差 | 报告捕获效率，用伪 bulk 验证 |
| 整合后组间差异消失 | 过度整合 | 降低整合强度，保留生物变异 |
| 轨迹方向相反 | 起点选择主观 | 用 RNA velocity/标记基因佐证 |
| 空间域与组织学不符 | 配准错误 | 重新对齐图像与坐标 |
