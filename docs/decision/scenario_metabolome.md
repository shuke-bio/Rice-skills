# 场景卡：代谢组（独立分析）

## 1. 适用与前提

- 数据：靶向或非靶向代谢物丰度矩阵 + 样本表；
- 前提：报告缺失率与插补策略；非靶向数据为**半定量**，不做绝对浓度推断；
- 目标：组间差异、通路、标志物、网络，或与基因型/转录组联合。

## 2. 先判断数据类型

| 类型 | 可做的事 | 不能做的事 |
|---|---|---|
| 靶向（绝对定量） | 组间比较、通路、标志物 | — |
| 非靶向（相对丰度） | 相对变化、通路、网络 | 绝对浓度、跨批次直接比较 |
| 组成型（相对比例） | CLR/对数比后的相关与判别 | 原始比例直接做相关/回归 |

## 3. 三档方案

### 最小可行
1. `metabolomics/01_preprocess.py`：缺失过滤/插补、归一化、QC；
2. PCA 与样本相关性（找离群）；
3. 报告检出代谢物数与缺失率。

### 标准
1. `metabolomics/02_oplsda.R`（OPLS-DA、VIP、置换检验）；
2. `metabolomics/03_pathway.R`（通路富集）；
3. `metabolomics/05_biomarker.R`（ROC/随机森林，需独立验证）。

### 进阶
1. `metabolomics/06_metabolite_network.R`（共表达网络）；
2. `metabolomics/04_metabolite_classification.R`（注释分类）；
3. `qtl/02_colocalization.R`（有基因型时做 mQTL 与共定位）。

## 4. 文献依据（白名单）

- 精米代谢组 + 高光谱 + mGWAS（Genome Biology 2025, doi:10.1186/s13059-025-03513-w）——
  低成本表型代理 + 关联 + 共定位的三段式设计；
- 植物代谢组学方法综述（Plant Physiology 2025）——预处理、归一化与质量控制；
- 水稻群体代谢组与抗虫（JIPB 2025）——代谢标志物到预测模型的路径。

## 5. 失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| OPLS-DA 完美分开 | 过拟合/样本少 | 置换检验 + 交叉验证 |
| 通路富集为空 | 代谢物 ID 未映射 | 统一 KEGG/ChEBI ID |
| 标志物在新数据失效 | 无独立验证 | 留出集或外部队列验证 |
| 相关矩阵大量强相关 | 组成型伪相关 | CLR/对数比变换 |
