# 场景卡：多组学整合（转录组 × 代谢组）

## 1. 适用与前提

- 数据：同一批样本的 ≥2 个组学层（最常见：转录组 + 代谢组）；
- 前提：**样本可匹配**（同一 ID/同一批次取样）；n≥20 才考虑因子模型；
- 目标：找跨层关联、模块、候选基因-代谢物对，或做 mQTL/eQTL 共定位。

## 2. 先判断"能不能整合"

| 问题 | 不通过时的替代 |
|---|---|
| 样本 ID 能一一对应吗？ | 不能 → 只能做组学各自的独立分析 |
| 两层是否同批次采集/处理？ | 不同批次 → 批次作为协变量，或分层分析 |
| n 是否 ≥20？ | <20 → 只做相关/共表达，不用 MOFA/DIABLO |
| 代谢物是相对丰度吗？ | 是 → 相关分析前做 CLR/对数比，避免组成型假相关 |

## 3. 三档方案

### 最小可行（先确认可匹配与整体结构）
1. `metabolomics/01_preprocess.py`：缺失填充、归一化、QC；
2. `transcriptomics/01_qc_filter.py`：表达矩阵质控；
3. 按样本 ID 取交集，输出匹配表与交集后 n。

### 标准（整合模型 + 跨层关联）
1. `metabolomics/02_oplsda.R`（组间判别、VIP）；
2. `integration/02_diablo.R`（有分组标签时的多组学判别）；
3. `integration/01_mofa.R`（无监督因子，n≥20 更稳）；
4. 基因-代谢物 Spearman 相关 + BH 校正。

### 进阶（网络与遗传定位）
1. `integration/05_network_integration.R`（模块-代谢物网络）；
2. `qtl/02_colocalization.R` / `03_coloc_bayesian.R`（mQTL/eQTL 共定位）；
3. `gwas/07_haplotype.R`（候选位点单倍型）。

## 4. 文献依据（方法学）

- **MOFA**：多组学因子分析，无监督、可处理缺失层（Argelaguet et al., Mol Syst Biol 2018, doi:10.15252/msb.20178157）；
- **DIABLO**：有监督多组学判别与变量选择（Singh et al., Bioinformatics 2019, doi:10.1093/bioinformatics/btz158）；
- **共定位（coloc）**：用 PP4 评估两性状共享因果变异；水稻应用示例见 Genome Biol 2025（doi:10.1186/s13059-025-03513-w）。

### 高分论文的设计启发（水稻）

- **精米代谢组 + 高光谱 + mGWAS**（Genome Biol 2025, doi:10.1186/s13059-025-03513-w）：先用低成本表型代理代谢物，再做 mGWAS 与共定位——适合样本量大但代谢检测贵的情况；
- **群体多组学（转录组 + 代谢组）**：先做单层关联，再做跨层共定位，避免把"相关"直接写成"调控"；
- **单细胞/空间 + 代谢**：目前多为探索性，需谨慎外推。

## 5. 失败模式与诊断

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 整合因子只反映批次 | 批次未建模 | 分层或把批次作为协变量 |
| 相关很强但生物学不合理 | 组成型数据/伪相关 | CLR 变换；检查驱动样本 |
| MOFA 方差解释很低 | 层间真实不相关 | 报告阴性结果，不强行解释 |
| 共定位 PP4 高但无功能证据 | LD 与样本量影响 | 加表达/单倍型/编辑验证 |
