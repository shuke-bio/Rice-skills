# 场景卡：GWAS（自然群体 / 家系 / 多亲本）

## 1. 适用与前提

- 数据：基因型（SNP/InDel/SV/PAV）+ 表型（含重复/多环境）+ 群体结构信息；
- 前提：**群体分层必须校正**；表型可靠（重复测量、区组设计）；
- 目标：定位显著位点、缩小候选区间、评估等位效应。

## 2. 先选设计，再选模型

| 设计 | 样本量建议 | 主力方法 | 备注 |
|---|---|---|---|
| 自然群体（3K/RDP 等） | ≥200–300 | GLM/MLM（PCA+K）、FarmCPU | 稀有变异功效低 |
| 双亲 RIL/F2 | 150–300 家系 | 连锁分析（QTL IciMapping 等） | 与关联分析互补 |
| MAGIC/NAM/ROAM | ≥300 家系 | mppQTL 两步法 | 需家系结构矩阵 |
| case-control | ≥200/组 | 逻辑回归 + 结构校正 | 病例对照比例影响功效 |

## 3. 三档方案

### 最小可行（先把结构与质控做对）

## 4. 文献依据（方法学）

- **3VmrMLM**：多位点 QTN + QTN×环境 + 上位性（Li et al., Mol Plant 2022, doi:10.1016/j.molp.2022.02.012）；
- **Fast3VmrMLM**：全基因组水平的快速多位点扫描（Plant Commun 2025, doi:10.1016/j.xplc.2025.101385）；
- **FarmCPU / MLM**：常用关联模型（实现见 `scripts/gwas/03_association.R`；不引用非白名单期刊原文）；
- **PLINK 1.9**：质控与格式转换（Chang et al., GigaScience 2015, doi:10.1186/s13742-015-0047-8）。

### 高分论文的设计启发（水稻）

- **图泛基因组 GWAS**（Nat Commun 2025）→ 把 SV/PAV 纳入关联，能找回参考基因组缺失的位点；
- **TWAS**（Nat Commun 2023）→ 用表达预测把关联信号映射到基因，适合"位点显著但候选太多"的场景；
- **mGWAS + 共定位**（Genome Biol 2025, doi:10.1186/s13059-025-03513-w）→ 代谢物作分子表型，显著提升候选基因分辨率；
- **Meta-GWAS**（多环境）→ 报告异质性与环境特有位点，而不是只给合并 P 值。

## 5. 失败模式与诊断

| 现象 | 可能原因 | 处理 |
|---|---|---|
| QQ 图整体膨胀（λ>>1） | 群体分层未校正 | 加 PCA/亲缘矩阵；检查家系结构 |
| 显著位点集中在着丝粒 | 低重组/重复区 | 剔除或标注，不作为候选 |
| 位点显著但候选基因很多 | LD 区间过大 | 加单倍型/表达/共定位证据 |
| 二分类结果不稳 | 样本不平衡 | 调整病例对照比例，报告 OR 与 CI |
| 多环境结果矛盾 | G×E 真实存在 | 用 QEI 模型，分别报告环境特有效应 |
