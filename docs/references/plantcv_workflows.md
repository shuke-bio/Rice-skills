# PlantCV 图像表型工作流——方法笔记

## 1. 适用场景

温室/大田台架成像的水稻整株或苗期性状量化：生长速率（投影面积时间序列）、形态
（叶倾角/株型宽高比）、颜色（干旱/氮素胁迫下的失绿）。输入是 RGB（或其他模态）图像
序列 + 采样元数据（基因型/处理/时间点），输出是"样本 × 特征"表——之后直接进入
`01_phenotype_blup.R`（BLUP/遗传力）或 GS 流程（`03_gs_gblup.R`）。

## 2. 流水线九步（语言重写）

1. **成像标准化**：固定背景（浅蓝/灰幕）、固定光源与相机参数；每批放色彩校正卡。
   标准化做得好，后面阈值分割的鲁棒性翻倍——这一步是田间表型成功率的最大杠杆。
2. **ROI 裁剪**：按花盆/托盘的已知坐标切出单株区域，去掉标尺、标签等无关物。
3. **植物/背景分割**（核心步）：
   - 灰度/单通道阈值：植物在蓝通道或 Lab 的 a 通道与背景区分度最高（绿植吸收红光）；
   - Otsu 自动阈值或手动直方图取阈；背景均匀时简单阈值就够；
   - 多方法投票：HSV 色相范围（绿色 ~40-90°）与暗度阈值取交集可抗高光/阴影；
   - 深度学习分割（可选升级）：预训练分割模型或自标注训练；小数据集不划算。
4. **掩膜清理**：形态学开/闭运算去噪点、填小洞、去最大连通域之外的碎片；
   保留最大轮廓（单株场景）或按面积阈值保留多株。
5. **对象分析**：对每个连通对象建立"轮廓→特征"记录；解析失败（无轮廓）要显式记账，
   不要静默跳过——QC 时要区分"没长出来"与"分割失败"。
6. **形态特征族**：投影面积（像素→cm² 需标尺换算）、周长、凸包面积与实度
   （solidity = 面积/凸包面积，反映叶片重叠/卷曲）、边界矩形长宽、椭圆长短轴与离心率、
   质心高度（株高代理）。**像素单位必须换算成物理单位**才可跨批次比较。
7. **颜色特征族**：在植物掩膜内做 HSV/色相聚类直方图（健康绿/失绿黄/坏死棕的占比）；
   比单均值更抗光照漂移。颜色特征对氮素/病害表型往往比形态更早响应。
8. **时间序列**：同一基因型多天扫描 → 每天特征 → 生长曲线拟合（logistic 或幂律），
   派生速率特征（AGR/CGR）。曲线参数比单日截面更遗传稳定（噪声平均掉）。
9. **批处理与 QC**：分析函数 + 元数据表驱动循环跑全批；每张图输出"分割质量指标"
   （掩膜面积占比、边界接触率——触到图像边缘的分割大概率是失败分割），事后统一审。

## 3. 与 Rice-skills 的衔接路径

| 图像表型输出 | 下游模块 |
|---|---|
| 样本 × 形态/颜色特征表（+ 物理单位） | `01_phenotype_blup.R` → BLUP/遗传力 → GWAS（模块 7） |
| 时间序列生长参数（AGR 等） | 直接作为表型性状列进入模块 7/15 |
| 失绿/颜色比例 | 胁迫评分 → 与代谢组/转录组联合（模块 3） |
| 多环境同一性状 | `04_ammi_gge.R`（GxE）与 `03_gs_gblup.R`（GS） |

## 4. 落地选择

- **直接用 PlantCV**（推荐生产环境）：`pip install plantcv`，其函数覆盖上述全部步骤；
  MPL-2.0 允许学术使用，注意保持其 LICENSE 与修改声明的合规即可。
- **用本包轻量替代**：小规模 RGB 批处理可用 OpenCV（`pip install opencv-python`）
  按上面九步自写 ~150 行；项目后续如加自研脚本会放在 `scripts/phenomics/` 并另行验证。
- **看图像表型的文献规范**：报告分割方法、样本数、失败率、物理换算依据——审稿常问。
