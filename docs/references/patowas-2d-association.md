# 参考笔记：2D 关联作图与 PATOWAS 方法导航

> 本笔记为**方法整理**（README/论文公开信息整理 + 领域知识归纳），不包含上游任何源码。
> 上游：<https://github.com/ZhaoBioinformaticsLab/PATOWAS>（GPL-3.0，独立程序，未打捆进本仓库）。
> 原始论文：Zhang W, Dai X, Xu S, Zhao PX. *2D association mapping and integrative omics
> analysis provides systems biology view in trait analysis.* Communications Biology, 2018.
> doi:10.1038/s42003-018-0159-7

## 1. 它解决什么问题

Rice-skills 现流程回答的是**"组内比较"**问题：两个/多个处理组之间哪些基因、代谢物发生了变化，
以及两者如何关联（少量样本、分组设计）。

PATOWAS 回答的是**"群体关联"**问题：在一个**大群体**（如 RIL 重组自交系、自然群体）中，
性状与组学标记（SNP / 基因表达 / 代谢物丰度）之间的统计关联，并且不止查**单个标记的主效应（1D）**，
还系统扫描**标记×标记的互作效应（2D）**——用于发现"上位性/协同"式的调控关系。

一句话：**DE 分析告诉你"处理改变了什么"，2D 关联作图告诉你"群体里什么在决定表型"。**

## 2. 方法内核（整理）

- **模型**：线性混合模型（LMM）。既估计标记的加性效应，也估计标记两两互作效应；
  随机效应通过亲缘/关系矩阵吸收群体结构（避免假阳性）。
- **两个核心矩阵**：
  - `ka`：加性关系矩阵（由基因型/表达量/代谢物丰度矩阵计算，类似 kinship）；
  - `kaa`：互作关系矩阵（刻画两两标记组合的相似性）。
- **方差组分分析**：估计各随机效应的方差占比，判断性状由多少"组学信号"解释。
- **全组学扫描**：1D 扫描（主效应 p 值）与 2D 扫描（互作效应 p 值），2D 计算量为 O(m²)，
  通常先用 1D 结果筛选候选标记再进 2D。
- **四个模块**：`km_calc`（关系矩阵）、`vc_anal`（方差组分）、`ps_main`（1D 扫描）、
  `ps_inter`（2D 扫描）。

## 3. 使用条件与局限

- 需要**同一群体**的三类数据：① 基因型（加性编码 0/1/2）或组学矩阵（表达/代谢物）、
  ② 性状表型、③ 群体个体名单对齐。**不适用于** 3 重复的小规模处理组实验。
- 上游代码为 2018 年 C++（Code::Blocks / Linux 编译），现代编译器下可能需要少量兼容性调整；
  模块间以文件交互，需按 README 顺序跑。GPL-3.0：修改/再分发需保持 GPL。
- 作为替代路线，若样本量中等且无系谱信息，可直接用 `correlation.R`（本包整合模块 03）
  做基因-代谢物相关，或用 GWAS 工具（GEMMA / GAPIT / FarmCPU）处理纯基因型关联。

## 4. 与本包的衔接建议

1. **先跑本包主流程**得到差异基因、差异代谢物与候选模块（WGCNA）；
2. 若你手上有**群体材料**（如水稻抗逆群体的 GWAS 数据），可把候选基因/代谢物
   作为"组学标记"接入 PATOWAS 做 2D 扫描，验证候选位点的互作效应；
3. 两条线路的候选列表可交叉比对（关联信号 ∩ 差异表达 = 高置信候选）。
